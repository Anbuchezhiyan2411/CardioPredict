Project Overview & Clinical Objectives

CardioPredict is a machine learning clinical decision-support system engineered for the early detection and risk stratification of coronary artery disease. Cardiovascular diseases (CVDs) remain the leading cause of mortality worldwide, accounting for an estimated 17.9 million lives each year according to the World Health Organization (WHO).

The objective of this academic data science capstone project is to demonstrate end-to-end data science lifecycle execution: from raw medical data ingestion, rigorous statistical auditing, and inferential hypothesis testing, to model benchmarking, artifact serialization, and web deployment.

Completed Project Lifecycle (Phases 1–9)

Phase 1: Project Setup & Data Ingestion — Verified Cleveland raw data, resolved missing headers, binarized diagnosis.
Completed

Completed
Phase 4: High-Resolution Data Visualizations — 10 clinical charts (Histograms, Box plots, Violin, Heatmaps, Scatter).
Completed
Phase 5: Inferential Hypothesis Testing — SciPy T-Test, Chi-Square test, One-Way ANOVA, and Pearson significance.
Completed

Completed
Phase 7: Machine Learning Model Training — Trained 5 distinct algorithms (LR, DT, RF, SVM, KNN) with hyperparameter tuning.
Completed
Phase 8: Comprehensive Model Evaluation — Multi-criteria benchmarking, ROC-AUC (0.9654), best model serialization.
Completed
